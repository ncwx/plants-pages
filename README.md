# Plants & Pages

A gamified reading tracker where users build a virtual garden based on their reading progress.

## Core Features (Planned)
- Book logging and CSV import
- XP + Seeds reward engine
- Garden builder with unlockable plants
- Friends + garden visits
- Reading analytics dashboard
- AI-powered reading theme clustering

## Tech Stack
- Next.js (Frontend)
- FastAPI (Backend)
- Supabase Postgres
- Render (API deploy)
- Vercel (Frontend deploy)

## Status
In active development

## Local Development
Prereqs: Node.js 18+, Python 3.11+, and GNU Make.

Setup dependencies:
- `make setup`

Run web + api:
- `make dev`

Run API tests:
- `make test-api`

Lint and format:
- `make lint`
- `make fmt`
